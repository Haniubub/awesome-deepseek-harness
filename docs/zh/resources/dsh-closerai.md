## 一句话介绍

CloserAI - a local-first, model-agnostic, permission-transparent desktop AI workbench built on DeepSeek Harness.

## 详细介绍

[简体中文](README.zh.md) | English CloserAI is an open-source desktop application that wraps a [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) process in a hardened Electron shell. It is not a reskin: it adds a desktop supervisor, three permission-isolated working modes (Chat / Work / Code), local-first session storage, provider management with OS-keychain secrets, and a plugin safety model — while delegating the agent runtime to DSH.
