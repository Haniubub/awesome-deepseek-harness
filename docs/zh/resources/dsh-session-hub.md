# dsh-session-hub

> ⭐ 4 · ✅ 活跃 · 集成

## 一句话介绍

Aggregate and natively control multiple remote DeepSeek Harness (DSH) servers' sessions from one official Web UI — hub gateway + official-UI bridge. 多服务器 DSH 会话聚合与原生操控

## 详细介绍

**把散在各处的会话收进 DSH 的同一棵树。** 远端服务器上的 DSH 会话，本机 Codex CLI、Claude Code、opencode、Pi 的历史对话， 一起进官方 Web UI。侧边栏和对话区都用官方的，插件只搬数据。两件事互相独立，可以只装一件。 <a href="https://www.npmjs.com/package/dsh-session-hub"></a> <a href="LICENSE"></a> <a href="CHANGELOG.md"></a> </div>
