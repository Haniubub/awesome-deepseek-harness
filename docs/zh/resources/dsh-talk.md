# dsh-talk

> ⭐ 5 · ✅ 活跃 · 集成

## 一句话介绍

Voice-first session loop for DeepSeek Harness: a composer microphone button with browser/local speech-to-text (Web Speech, FunASR, whisper.cpp), a speak tool for text-to-speech replies (browser, edge-tts, piper), event announcements with mute, and speak-to-interrupt.

## 详细介绍

- **1024 store channel**: `npm i -g dsh1024` once, then `dsh1024 plugin --profile web add dsh-talk` (counts toward the [deepseek1024.com](https://deepseek1024.com) install ranking). **Voice-first session loop for DeepSeek Harness: talk to it, hear it answer.** *Press the mic, speak, and the reply is spoken back — with speak-to-interrupt.* [English](README.md) · [简体中文](README.zh.md) · [Español](README.es.md) · [Português](README.pt.md) · [हिन्दी](README.hi.md) </div> ---
