# dsh-recall-plugin

> ⭐ 21 · ✅ 活跃 · 插件

## 一句话介绍

DSH 消息撤回插件：回到发送该消息时的状态 DSH Message Recall Plugin: Return to the state when the message was sent

## 详细介绍

--- **在任意一条你发过的消息下方**，**点「↶ 撤回」**，**工作区文件和对话历史一起回到那条消息发出之前的状态**。
