## 一句话介绍

Specification-driven development toolkit for DeepSeek Harness.

## 详细介绍

<p align="center"> </p> Turn an idea into a reviewable specification, implementation plan, task list, and resumable [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) goal. SpecFlow stores the work in the repository instead of one conversation. A later session can read the same artifacts, recover the next unchecked task, and resume the matching durable DSH goal.
