# dsh-wallpaper

> ⭐ 4 · ✅ 活跃 · 插件

## 一句话介绍

Wallpaper skin for the DeepSeek Harness (dsh) web UI: image background with opacity, mask and blur controls.

## 详细介绍

用一张图片作为 DSH Web 界面的窗口背景，并可通过右下角小面板实时控制： - **图片透明度**（0–100%） - **面板透明度**（0–100%，越小背景图越透） - **压暗遮罩**（0–100%，提高文字可读性） - **背景模糊**（0–40px）
