# dsh-plugins-store

> ⭐ 3 · ✅ 活跃 · 精选列表

## 一句话介绍

Browse and install DSH plugins from inside DeepSeek Harness. /store, a settings tab, and agent tools — bilingual.

## 详细介绍

dsh plugin --profile web add dshmarketplace-plugin Then `/store` in any session, or **Settings → Plugins → Plugin store**. `--profile` is not optional. `dsh plugin` forwards to pnpm inside a profile directory, so `dsh plugin add x` exits with *required option '--profile &lt;name&gt;' not specified* and installs nothing. Swap `web` for your profile if you run another one.
