> ⭐ 25 · ✅ 活跃 · 插件

## 一句话介绍

Fix and diagnose DeepSeek Harness on native Windows. Official PowerShell, Workspace Write, shortcuts, and legacy preset repair. No WSL.

## 详细介绍

**Official PowerShell. Workspace Write. One command.** npx dsh-win32 setup Current DeepSeek Harness already includes persistent PowerShell and a Windows ACL sandbox. dsh-win32 checks that official stack, finds known Windows failures, applies the repairs it can prove safe, and creates a desktop shortcut. It does not install Git, PowerShell, busybox, WSL, or another DSH bundle on the current path. [中文](./docs/README.zh.md) · [Windows evidence and legacy details](./docs/windows-details.md) <p> <a h
