# dsh-vscode

> ⭐ 12 · ✅ 活跃 · 集成

## 一句话介绍

DSH Sidebar — a Claude Code/Codex-style VS Code sidebar for DeepSeek Harness. 像 Claude Code、Codex 一样，在 VS Code 侧边栏中使用 DSH。

## 详细介绍

Bring DeepSeek Harness into the same place you write code. dsh-vscode gives DSH a Claude Code/Codex-style right sidebar that already understands your project, active file, and selected code. Ask DeepSeek to inspect, change, and verify code without switching between your editor, terminal, and a separate chat window. <p align="center"> </p>
