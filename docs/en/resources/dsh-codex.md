## About

Use a ChatGPT subscription in [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) through OpenAI's Codex sign-in flow—no OpenAI Platform API key required and no dsh source patch required. `dsh-codex` is an independent dsh bundle. It adds: - ChatGPT OAuth from the dsh Settings panel or a standalone CLI, with automatic token refresh - the Codex GPT catalog, including vision-capable models when the account offers them - streaming, tool calls, reasoning replay, prompt caching, and ds
