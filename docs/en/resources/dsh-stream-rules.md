## About

[简体中文](README.zh.md) Inject rules when needed, without wasting context. You can write custom streaming rules for the agent. These rules are injected only as a steering notice after a pattern match, then agent retry from the same point. This allows you to control the boundaries of agent behavior, without wasting context.
