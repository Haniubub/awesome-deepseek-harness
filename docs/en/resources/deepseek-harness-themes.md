## About

[English](README.md) | [简体中文](README.zh.md) A collection of UI themes for [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness). Community-maintained theme collection built on the official theme extension point (`ctx.theme` from `@deepseek-ai/dsh-client-ui-theme`). It focuses only on the visual experience — colors, surfaces, states, code blocks, tool calls, terminal UI. No model changes, no agent changes, no prompt changes, no protocol changes.
