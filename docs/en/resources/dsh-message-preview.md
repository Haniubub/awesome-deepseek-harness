# dsh-message-preview

> ⭐ 7 · ✅ active · integration

## One-liner

Right-side user-message navigator for the DeepSeek Harness Web UI.

## About

DeepSeek Harness Web UI 的右侧消息导航条。它为当前会话中的每条用户消息生成一个导航块，可悬停预览、显示当前阅读位置，并点击跳转到对应消息。
