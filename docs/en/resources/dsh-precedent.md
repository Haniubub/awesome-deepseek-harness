# dsh-precedent

> ⭐ 0 · ✅ active · plugin

## One-liner

Evidence-backed working memory for DeepSeek Harness: a cited ledger of what already worked in this workspace, built from the session log you already have. No index, no model, no capture step.

## About

**Your agent forgets. Your log doesn't.** </div> A [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) plugin that reads the session log DSH already writes and hands the agent a short, **cited** ledger of what has actually worked in this workspace — the commands that succeed, the ones that reliably fail, and the variant that fixed them. No capture step. No index to build. No model to download. It works on sessions recorded **before** you installed it.
