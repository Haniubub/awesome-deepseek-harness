## About

**DeepSeek Harness 免费搜索插件 —— 无需 API key，零成本，多引擎可切换。** 一个给 DeepSeek Harness (dsh) 添加多引擎搜索 provider 的插件，注册进 `ctx.web` seam。内置 `web_search` 工具自动选用，支持网页设置页切换引擎、配置 API key、一键测试所有引擎。 [English](./README.en.md) | 中文 <div align="center"> <a href=""> </a> <br> <sub>▲ 免费引擎（以Bing为例）</sub> </div>
