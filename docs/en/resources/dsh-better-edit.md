# dsh-better-edit

> ⭐ 19 · ✅ active · plugin

## One-liner

Hash-anchored read/edit/undo_last_edit tools for DeepSeek Harness (dsh), fewer token consumption, lower cost.

## About

**If you've watched an agent corrupt a file because `line 47` became `line 74` after an insert — this is for you.** Not for one-line touch-ups (near parity) or brand-new files (`write`). It pays off in long sessions and structural edits — anywhere an edit must not land on the wrong line.
