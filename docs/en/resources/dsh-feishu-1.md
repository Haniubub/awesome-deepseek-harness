# dsh-feishu

> ⭐ 10 · ✅ active · integration

## One-liner

通过扫码把飞书机器人接入DeepSeek Harness

## About

把一个或多个飞书机器人直接接入 DeepSeek Harness。安装插件后，在 Harness 的设置页扫码即可逐个创建机器人；每次确认完成并通过连接检查后，都能立即在飞书里与同一个 Harness 智能体连续对话。
