# Open Sea Skin

> ⭐ 181 · ✅ active · plugin

## One-liner

Realtime WebGPU ocean skin with controls for waves, daylight, glass opacity and automatic day cycling.

## About

[中文](README.zh.md) · [Architecture](docs/architecture.md) · [Release guide](docs/releasing.md) A self-contained WebGPU ocean for new tabs and DeepSeek Harness. It keeps the original five-wave Gerstner/TSL look, adds a translucent Harness theme, and is available as a one-line DSH plugin, Chrome/Edge extension, one-command static installer, or native Harness source integration.
