# dsh-session-pin

> ⭐ 3 · ✅ active · plugin

## One-liner

Pin sessions and workspaces to the top of the DeepSeek Harness sidebar with per-pin row colors - a dual-face (host + client) dsh plugin.

## About

- **1024 store channel**: `npm i -g dsh1024` once, then `dsh1024 plugin --profile web add dsh-session-pin` (counts toward the [deepseek1024.com](https://deepseek1024.com) install ranking). **Pin sessions and workspaces to the top of the DeepSeek Harness sidebar with per-pin row colors.** *A dual-face (host + browser) plugin: two pin levels, an 8-color swatch per pin, and a navigation organizer — boards, tags, saved views, health summaries, and `/goto`.* [English](README.md) · [简体中文](README.zh.md
