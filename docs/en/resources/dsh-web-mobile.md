## About

从 GitHub 一行装： dsh plugin --profile web add github:mexiaosqwq/dsh-web-mobile 仓库自带构建产物，无 `allowBuilds` 拦截。装完重启 `dsh web`。 本地开发： dsh plugin --profile web add link:/path/to/dsh-web-mobile
